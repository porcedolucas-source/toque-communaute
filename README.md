# Toque — communauté

Toque est une app d'enregistrement audio pour iPhone et Mac, transparente et respectueuse du consentement : l'enregistrement se voit toujours (point orange, bandeau), un appel enregistré s'annonce de vive voix, et rien n'est capté à l'insu de quiconque. Tout reste dans la destination que vous choisissez (iCloud Drive, NAS, serveur WebDAV), et la transcription se fait sur l'appareil.

Ce dépôt sert à échanger, pas à distribuer le code :

- **Discussions** : idées, questions, retours d'usage, annonces des nouvelles versions.
- **Signalements** (onglet Issues) : un problème, avec la version, l'appareil et le système. Dans Toque, Réglages > Communauté > « Signaler un problème » les remplit pour vous.

Avant de publier, relisez : un enregistrement, une transcription ou le journal de diagnostic peuvent citer des personnes. Ne les joignez qu'après les avoir relus, et jamais ceux d'autres personnes.

Une demande qui contournerait les indicateurs d'enregistrement ou le consentement des personnes ne sera pas suivie.
